# What it is

**Pierre-Paul Grassé, 1959**, in *Insectes Sociaux* — coined **stigmergie** from
observing termite nest construction (*Bellicositermes natalensis*). The idea: the
work already done is what stimulates the next action. Agents coordinate by
modifying a **shared environment**, not by communicating with each other.

# What we use it for

[paradigm](/../../VoidAllomone/okf/concepts/paradigm.md) and
[foundations §4](/../../VoidAllomone/okf/concepts/foundations.md): Allomone is **stigmergic in
coordination topology**. Rules never reference each other; they read and write a
shared medium, and the graph is the message.

**The name also carries a distinction we rely on**
([index](/../../VoidAllomone/okf/index.md)): a **pheromone** is *intraspecific* — a
signal to one's own kind — while an **allomone** is an *allelochemical* that
crosses a species boundary, read by whoever can read it. That is why the name is
more precise than it first appears: a rule is a statement dropped into a shared
environment and acted on by anything able to interpret it.

**What we explicitly refuse** is stigmergy's *physics*: no decay, no evaporation,
no stochastic agents, no temporal dynamics. Borrowing the topology while
declining the dynamics is a deliberate line, and stating it is what stops the
analogy from being invoked to justify features it does not imply.

# Why it is credible

Grassé is the primary source for the term itself — for a coinage, that is the
strongest form of citation available. The concept is standard in swarm
intelligence and multi-agent systems.

# What a verification pass should check

- **Grassé**, **1959**, *Insectes Sociaux*, and the termite species.
- That **stigmergie** is his coinage rather than a later formalization
  attributed back to him.
- **The pheromone/allomone distinction**: that *allomone* is correctly an
  interspecific allelochemical, and specifically one benefiting the emitter.
  *(Worth checking — the allelochemical family also contains kairomones and
  synomones, which differ by who benefits, and the naming argument in
  `index.md` depends on getting the right one.)*
